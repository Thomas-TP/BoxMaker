# Boxmaker v0.5.0 — Refreshed workspace and simpler updates

> **Historical release.** The unsigned Windows installer was removed. [Download the current Boxmaker release](https://github.com/Thomas-TP/BoxMaker/releases/tag/v0.8.3). The files attached below are retained for automatic updates of existing installations.

The interface gains a blue-and-slate palette, a larger 3D preview, and clearer controls. The complete box-and-lid export sits near the top of the right panel, with a toolbar shortcut on narrow windows.

- Removed the PLA-saving comparison with the earlier box.
- Settings and shipping scroll in separate panels on wide windows, with a layout adapted for smaller ones.
- Cavity and spring details collapse; the legacy model selector lives in advanced settings.
- Numeric values are selected on focus for faster editing. Dialogs support keyboard navigation and Escape.
- A change of printer or print-bed margin clears a previously entered parcel weight when it can change the selected orientation.

The **Updates** button is available in the toolbar. After downloading an update, **Install and restart** can proceed without saving the current model. **Save project, then install** remains a separate option. Download state survives closing and reopening the update dialog; restarting discards unsaved changes.

The Windows build and interface rendering were checked. At the user's request, the test suite was not run for this version; functional testing, including a real update cycle, remained outstanding. Mechanical geometry was unchanged from v0.4.0.

`releases.win.json` and the full `.nupkg` are update files, not manual installers. Their hashes are in `SHA256SUMS.txt`.
