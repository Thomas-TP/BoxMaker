# Boxmaker v0.8.0 — Microsoft Store launch

> **Historical release.** For the current version, [download Boxmaker v0.8.3](https://github.com/Thomas-TP/BoxMaker/releases/tag/v0.8.3). The unsigned Windows installer for this version has been removed.

Boxmaker became [available for free in Microsoft Store](https://apps.microsoft.com/detail/9MX7QLK05FJP) under the publisher name **ThomasTP**. This release includes [Boxmaker-Windows.exe](https://github.com/Thomas-TP/BoxMaker/releases/download/v0.8.0/Boxmaker-Windows.exe), a small Microsoft-signed web installer. It requires an internet connection and installs the version currently offered by the Store, not necessarily v0.8.0. Microsoft Store also handles updates for that installation. The unsigned MSIX submitted to Partner Center is not attached to GitHub Releases.

The interface now makes clear that the complete 3MF export contains three parts: box, lid, and printable seal. The seal geometry is unchanged from v0.7.0. Its transport strength and break behavior still need physical testing.

The `releases.win.json` and `*.nupkg` files are required for existing Windows installations to update; they are not manual installers. Their hashes are listed in `SHA256SUMS.txt`.
