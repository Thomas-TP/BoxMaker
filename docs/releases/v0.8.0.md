# Boxmaker v0.8.0 — disponible sur le Microsoft Store

Boxmaker est [disponible gratuitement sur le Microsoft Store](https://apps.microsoft.com/detail/9MX7QLK05FJP), sous l’éditeur **ThomasTP**. Cette release joint [Boxmaker-Microsoft-Store-Web-Installer.exe](https://github.com/Thomas-TP/BoxMaker/releases/download/v0.8.0/Boxmaker-Microsoft-Store-Web-Installer.exe), un petit installateur Web **signé par Microsoft** qui télécharge l’application depuis le Store et nécessite Internet. Pour obtenir une copie fraîche, utiliser le [lien direct Microsoft](https://apps.microsoft.com/detail/9MX7QLK05FJP?mode=direct). Microsoft distribue la version Store signée et gère ses mises à jour. L’installateur Web n’est pas le MSIX complet ; le MSIX non signé envoyé à Partner Center **n’est pas joint à cette release GitHub**.

L’installateur `Swiss3Design.Boxmaker-win-Setup.exe` publié sur GitHub est **non signé**. Windows peut afficher « Éditeur inconnu ». L’application installée avec cet EXE conserve les mises à jour depuis GitHub, et l’utilisateur peut toujours installer une mise à jour sans enregistrer le projet en cours.

L’interface précise maintenant que l’export 3MF complet contient trois pièces : boîte, couvercle et scellé. La géométrie du scellé n’a pas changé depuis v0.7.0 ; sa tenue au transport et sa rupture restent à vérifier sur une impression réelle.
