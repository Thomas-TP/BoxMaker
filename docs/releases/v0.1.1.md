# Boxmaker v0.1.1 — First Windows preview

> **Historical release.** The unsigned Windows installer was removed. [Download the current Boxmaker release](https://github.com/Thomas-TP/BoxMaker/releases/tag/v0.8.3). The files attached below are retained for automatic updates of existing installations.

Enter the dimensions of an object to generate a printable PLA box, preview its parts, and compare Swiss Post services using the box's outer dimensions and complete weight.

- **Bambu Lab P1S (256³ mm)** and **Creality K2 (260³ mm)** printer profiles.
- Adjustable box, sliding lid, separate locking key, walls, base, padding, and fit clearance.
- Three 3D views and separate STL/3MF exports in millimetres.
- Swiss Post letter and parcel estimates based on rates checked on 7 September 2026.
- Estimated PLA weight and material cost, plus an input for the actual closed-parcel weight.
- Projects can be saved and reopened without a Boxmaker account.
- On-demand GitHub update checking from the app.

**Before shipping:** This was a functional software prototype, not a physically validated shipping box. Print a small test box, adjust the fit, and test closure before packing anything. PLA impact and compression resistance had not been validated. Check excluded print-bed areas, use an appropriate PLA profile, secure the separate key with tape, and weigh the closed parcel. The 3MF contains geometry, not printer settings or G-code. Postal estimates need confirmation with Swiss Post; the 2026 rate table will need an update for 2027.

This release corrected CSS line endings for a fresh Windows checkout and ensured that every published file was covered by `SHA256SUMS.txt`. The v0.1.0 tag failed in CI and did not produce a public release. A complete real-world update cycle was not yet verified.

`releases.win.json` and the full `.nupkg` are update files, not manual installers.
