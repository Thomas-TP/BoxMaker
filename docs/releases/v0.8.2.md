# Boxmaker v0.8.2 — Windows ARM64

Boxmaker dispose désormais d’une version **Windows ARM64 native**. Si votre PC Windows possède un processeur ARM (par exemple Snapdragon), choisissez l’installateur `Swiss3Design.Boxmaker.Arm64-win-arm64-Setup.exe` ou son ZIP portable. La version x64 reste disponible pour les PC Intel et AMD. Sur Windows 11 ARM, l’ancienne version x64 peut fonctionner par émulation ; la nouvelle version évite cette couche et permet aussi de viser Windows 10 ARM.

Les installateurs GitHub restent **non signés** et Windows peut afficher « Éditeur inconnu ». Le **Microsoft Store Web Installer** fourni dans la release est signé par Microsoft et télécharge la version actuellement publiée sur le Store ; elle peut temporairement différer de cette release GitHub. Les paquets MSIX x64 et ARM64 sont soumis séparément au Store et ne figurent pas dans la release tant qu’ils ne sont pas signés par Microsoft.

Le DMG macOS universel Intel/Apple Silicon reste une **préversion non testée en conditions réelles**. Le build, la signature ad hoc et l’intégrité du disque sont vérifiés automatiquement, mais l’installation et les fonctions de l’application n’ont pas été essayées manuellement sur Mac. Le build ARM64 Windows est également vérifié en CI, sans essai manuel sur un PC ARM à ce stade.

Le scellé imprimable reste un prototype à vérifier par impression et envoi réels.
