# Boxmaker v0.8.2 — Windows ARM64

| Votre ordinateur | Télécharger |
| --- | --- |
| **Windows** (Intel, AMD ou ARM) | [Installer Boxmaker avec Microsoft Store](https://github.com/Thomas-TP/BoxMaker/releases/download/v0.8.2/Boxmaker-Windows.exe) |
| **Mac** (Intel ou Apple Silicon) | [Télécharger le DMG macOS](https://github.com/Thomas-TP/BoxMaker/releases/download/v0.8.2/Boxmaker-0.8.2-macOS.dmg) |

L’installateur Windows est signé par Microsoft. Il nécessite Internet, installe la version actuellement disponible dans le Store et choisit l’architecture adaptée à votre PC. Cette version peut différer de la version indiquée dans le nom de la release GitHub.

**Nouveauté :** Boxmaker possède désormais une version Windows ARM64 native pour les PC à processeur ARM, comme certains modèles Snapdragon. Le Store la sélectionne automatiquement. Le build ARM64 a été vérifié automatiquement, mais n’a pas encore été essayé manuellement sur un PC ARM.

**Mac : préversion non testée en conditions réelles.** Le DMG universel est vérifié automatiquement et signé localement, sans certificat Apple ni notarisation. Son installation et les fonctions de l’application n’ont pas encore été essayées sur un Mac. macOS peut demander d’autoriser la première ouverture dans **Réglages Système → Confidentialité et sécurité → Ouvrir quand même**.

Les fichiers `releases.win*.json` et `*.nupkg` servent aux mises à jour des anciennes installations Windows. Ils ne sont pas des installateurs à télécharger manuellement. `SHA256SUMS.txt` contient les empreintes de tous les fichiers joints.

Le scellé imprimable reste un prototype à vérifier par impression et envoi réels.
