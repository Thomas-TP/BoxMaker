# Boxmaker v0.8.2 — Native Windows ARM64

| Your computer | Download |
| --- | --- |
| **Windows** (Intel, AMD, or ARM) | [Install Boxmaker via Microsoft Store](https://github.com/Thomas-TP/BoxMaker/releases/download/v0.8.2/Boxmaker-Windows.exe) |
| **Mac** (Intel or Apple Silicon) | [Download the macOS DMG](https://github.com/Thomas-TP/BoxMaker/releases/download/v0.8.2/Boxmaker-0.8.2-macOS.dmg) |

The Windows web installer is signed by Microsoft. It requires an internet connection, chooses the appropriate architecture, and installs the version currently available in Microsoft Store. That Store version may differ from the version in this GitHub release's title.

**What's new:** Boxmaker now has a native Windows ARM64 build for ARM-based PCs, including Snapdragon devices. Microsoft Store chooses it automatically. The ARM64 build passed automated checks, but it has not yet been tested manually on an ARM PC.

**Mac preview:** The universal DMG passed automated build, disk-image, and ad hoc signature checks. It has no Apple Developer certificate or notarization, and installation and app features have not yet been tested on a physical Mac. macOS may require you to allow the first launch in **System Settings → Privacy & Security → Open Anyway**.

The `releases.win*.json` and `*.nupkg` files support updates for existing Windows installations; they are not manual installers. `SHA256SUMS.txt` lists checksums for the attached files.

The printable seal remains a prototype. Test a real print and shipment before relying on it.
