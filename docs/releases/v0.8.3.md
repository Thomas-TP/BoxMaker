# Boxmaker v0.8.3 — English and French in the app

| Your computer | Download |
| --- | --- |
| **Windows** (Intel, AMD, or ARM) | [Install Boxmaker via Microsoft Store](https://github.com/Thomas-TP/BoxMaker/releases/download/v0.8.3/Boxmaker-Windows.exe) |
| **Mac** (Intel or Apple Silicon) | [Download the macOS DMG](https://github.com/Thomas-TP/BoxMaker/releases/download/v0.8.3/Boxmaker-0.8.3-macOS.dmg) |

The Windows web installer is signed by Microsoft. It requires an internet connection and installs the version currently available in Microsoft Store. The Store version may differ from this GitHub release until its update is published.

**What's new:** Choose English or French in the app. Boxmaker also detects your system language on first launch and remembers your choice. The Microsoft Store has listings in both languages. The README, user guide, and release notes are in English. Exported projects now default to `boxmaker-project.boxmaker.json`, and the complete three-part model downloads as `boxmaker-all-parts-PLA.3mf`. The other part exports already use English names. The Mac download badge now uses Boxmaker's logo.

**Mac preview:** The universal DMG is built and checked automatically, but has not yet been tested on a physical Mac. It has no Apple Developer certificate or notarization. If macOS blocks the first launch, use **System Settings → Privacy & Security → Open Anyway** after opening the app.

The `releases.win*.json` and `*.nupkg` files support updates for existing Windows installations; they are not manual installers. `SHA256SUMS.txt` lists checksums for the attached files.

The printable seal remains a prototype. Test a real print and shipment before relying on it.
