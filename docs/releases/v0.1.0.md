# Boxmaker v0.1.0 — First Windows preview

**Unpublished build.** This tag failed in CI; v0.1.1 became the first public release. [Download the current Boxmaker release](https://github.com/Thomas-TP/BoxMaker/releases/tag/v0.8.3).

Enter an object's dimensions to generate a printable PLA box, preview its parts, and compare Swiss Post services using the box's outer dimensions and complete weight.

The preview introduced Bambu Lab P1S (256³ mm) and Creality K2 (260³ mm) printer profiles; adjustable walls, base, padding, and clearance; a box, sliding lid, and separate locking key; three 3D views; separate STL/3MF exports in millimetres; estimated PLA weight and material cost; actual parcel weight entry; locally saved projects; and on-demand GitHub update checking. Swiss Post letter and parcel estimates used rates checked on 7 September 2026.

This was a functional software prototype without physical validation of PLA impact resistance, compression strength, or object protection. Print a small test box and verify closure first. Check excluded print-bed areas and slicer settings, secure the locking key with tape, and weigh the closed parcel before buying postage. The 3MF contains geometry, not printer settings or G-code. Shipping rates are estimates, and the 2026 rate table will need an update for 2027.
