# Boxmaker v0.8.1 — préversion macOS

Boxmaker est désormais proposé pour **macOS** en plus de Windows. Le fichier `Boxmaker-0.8.1-macOS-Universal-UNTESTED.dmg` contient une application pour les Mac **Apple Silicon et Intel**. Ouvrez le DMG, puis glissez Boxmaker dans Applications.

**Version macOS non testée en conditions réelles.** Le code et le DMG sont construits sur un runner macOS ; l’intégrité du disque et la signature ad hoc sont vérifiées automatiquement. L’interface, l’aperçu 3D, les exports et l’installation n’ont pas encore été essayés manuellement sur un Mac. Vos retours sont les bienvenus dans les [issues](https://github.com/Thomas-TP/BoxMaker/issues).

Le DMG est **sans certificat Apple Developer et non notarisé**. macOS peut bloquer sa première ouverture. Si vous faites confiance au fichier téléchargé depuis cette release, essayez de l’ouvrir, puis allez dans **Réglages Système → Confidentialité et sécurité → Ouvrir quand même**. La version Mac ne se met pas encore à jour automatiquement : téléchargez une nouvelle version depuis les releases GitHub.

Pour **Windows**, l’installateur classique `Swiss3Design.Boxmaker-win-Setup.exe` reste non signé et peut afficher « Éditeur inconnu ». Le fichier `Boxmaker-Microsoft-Store-Web-Installer.exe` est signé par Microsoft et installe la [version disponible sur le Microsoft Store](https://apps.microsoft.com/detail/9MX7QLK05FJP), qui peut différer de cette release GitHub. Les trois canaux de téléchargement sont gratuits.

Le scellé imprimable reste un prototype à vérifier avec une impression et un envoi réels.
