# Boxmaker v0.8.1 — macOS preview

> **Historical release.** For the current version, [download Boxmaker v0.8.3](https://github.com/Thomas-TP/BoxMaker/releases/tag/v0.8.3). The unsigned Windows installer for this version has been removed.

Boxmaker is now available as a [universal macOS DMG](https://github.com/Thomas-TP/BoxMaker/releases/download/v0.8.1/Boxmaker-0.8.1-macOS.dmg) for Intel and Apple Silicon Macs. Open the DMG and drag Boxmaker to Applications.

**The Mac build has not been tested on a physical Mac.** The build, disk-image integrity, and ad hoc signature passed automated checks. Installation, the interface, 3D preview, and exports still need a hands-on test. Please report issues in the [issue tracker](https://github.com/Thomas-TP/BoxMaker/issues).

The DMG has no Apple Developer certificate or notarization. If you trust the file from this release and macOS blocks its first launch, try opening the app and then use **System Settings → Privacy & Security → Open Anyway**. Mac updates are currently downloaded from GitHub Releases.

For Windows, [Boxmaker-Windows.exe](https://github.com/Thomas-TP/BoxMaker/releases/download/v0.8.1/Boxmaker-Windows.exe) is signed by Microsoft and installs the version currently available in Microsoft Store, which may differ from v0.8.1. The printable seal remains a prototype requiring a real print and shipment test.

The `releases.win.json` and `*.nupkg` files are required for existing Windows installations to update; they are not manual installers. Their hashes are listed in `SHA256SUMS.txt`.
