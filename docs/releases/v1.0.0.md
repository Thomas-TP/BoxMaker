The Windows web installer is signed by Microsoft, needs internet, and installs the version currently published in Microsoft Store. That version may differ from this release while the Store update is being certified.

## What's new

- An interactive 3D fallback works without WebGL or GPU acceleration, including macOS virtual machines.
- Your last valid project is recovered automatically after closing or updating the app. Saving a project file remains optional during an update.
- Stable updates are the default. macOS and Windows Velopack installations can opt into beta releases in Updates. Microsoft Store installations use the Store's stable updates.
- macOS gains in-app update checks, verified update downloads, and installation with restart. Update checks on startup can be disabled.
- Project formats 1–5 remain supported, with validation and migration in Rust, clear errors for damaged or newer projects, and measured-weight invalidation when geometry changes.
- Rapid parameter edits keep only the latest pending calculation. Preview rendering runs when the view changes instead of continuously.
- English and French cover new controls, validation errors, recovery, and update messages.
- A note explains Bambu Studio's expected warning for 3MF files created outside Bambu Studio.
- Boxmaker is open source under the MIT license.

## Validation and installation notes

The maintainer confirmed printed closure and seal operation, loaded-box transport, Windows x64 installation/updates, macOS use, and Bambu Studio exports. Windows ARM64 is built in CI but has not been tested on a user device. See the [validation record](https://github.com/Thomas-TP/BoxMaker/blob/v1.0.0/docs/VALIDATION.md) for scope and remaining limits.

The Mac app retains a free ad hoc signature, without Apple Developer ID or notarization. If macOS blocks the first launch, use **System Settings → Privacy & Security → Open Anyway** after opening it. Move the app to Applications before updating. Users of Mac 0.8.x must install this DMG once to gain the updater. Its first real upgrade remains to be verified on a Mac.

Shipping estimates cover domestic Swiss shipments using the published 2026 rate table. Prices are hidden after its validity expires. Weigh the packed box and confirm postage with Swiss Post. The seal indicates normal opening; it cannot guarantee tamper resistance.

**Only the Windows EXE and Mac DMG are manual installers.** The `*.nupkg`, `releases.win*.json`, `*-macOS-update.tar.gz`, and `mac-updater.json` files are used by existing installations for updates. `SHA256SUMS.txt` contains the download checksums. Unsigned Store submission MSIX files are not published here.
