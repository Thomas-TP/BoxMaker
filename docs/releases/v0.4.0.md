# Boxmaker v0.4.0 — boîte et couvercle dans un seul fichier

Le bouton **Exporter les 2 pièces** télécharge un seul **3MF contenant la boîte et le couvercle**. Cette option est sélectionnée par défaut. Les pièces sont des objets indépendants, posés à plat côte à côte avec 15 mm d’espacement, comme dans la vue « Pièces à plat ».

Dans le slicer, les objets restent déplaçables séparément. Réorganiser les pièces ou les répartir sur plusieurs plateaux si l’ensemble ne tient pas sur un seul plateau. Le fichier ne contient ni profil d’impression ni G-code.

- Les exports individuels STL et 3MF restent accessibles dans le menu « Pièce ».
- Avec le modèle historique à clavette, l’export complet contient ses trois pièces.
- L’export complet est bloqué si une seule des pièces dépasse le volume utile de l’imprimante choisie.
- La géométrie, les réglages et les projets existants sont conservés.

## Validation

23 tests Rust réussis, contrôles Biome/TypeScript/Clippy et parcours navigateur incluant les téléchargements complets à deux et trois pièces. Les fichiers téléchargés ont été relus pour vérifier les objets, les maillages fermés, l’espacement et la pose à Z = 0. Le 3MF à deux pièces a été importé puis réexporté avec succès par Bambu Studio, qui conserve deux éléments d’impression indépendants.

Le fichier suit les objets et éléments de construction du [format 3MF Core](https://github.com/3MFConsortium/spec_core/blob/master/3MF%20Core%20Specification.md). Le placement côte à côte sert à l’inspection ; il ne remplace pas l’organisation du plateau dans le slicer.

## Installation

Utiliser `Swiss3Design.Boxmaker-win-Setup.exe`, le ZIP portable ou la recherche de mises à jour de l’application. Les empreintes des fichiers sont dans `SHA256SUMS.txt`.

Préversion : les limites mécaniques de v0.3.0 restent applicables. Les exécutables ne sont pas signés par certificat d’éditeur.
