# Boxmaker v0.4.0 — Box and lid in one file

> **Historical release.** The unsigned Windows installer was removed. [Download the current Boxmaker release](https://github.com/Thomas-TP/BoxMaker/releases/tag/v0.8.3). The files attached below are retained for automatic updates of existing installations.

The complete export now saves **one 3MF containing the box and lid**. This option is selected by default. The parts remain independent objects, placed flat with 15 mm between them, as in the print-layout view. You can move them separately in a slicer or place them on different plates. The file contains neither a print profile nor G-code.

- Individual STL and 3MF exports remain available.
- The legacy key-based model exports all three of its parts together.
- A complete export is blocked if any part exceeds the selected printer's build volume.
- Existing geometry, settings, and projects remain compatible.

Validation included 23 Rust tests, Biome, TypeScript, Clippy, browser checks, and inspection of downloaded two- and three-part files for object count, closed meshes, spacing, and placement at Z = 0. Bambu Studio imported and re-exported the two-part 3MF while preserving two independent printable objects. The layout is for inspection; arrange the build plate in your slicer.

The mechanical limitations from v0.3.0 still apply. `releases.win.json` and the full `.nupkg` are update files, not manual installers. Their hashes are in `SHA256SUMS.txt`.
